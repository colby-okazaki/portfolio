    Group Restaurant Matcher

    Friends join a group with a 4-digit code, swipe yes or no on nearby restaurants, and get a match when everyone agrees. I built the back end and co-designed the REST API with the front-end developer. Phones that drop off catch up when they reconnect, and swipes are safe to retry. Load tested with 1,200 live connections across 200 groups: zero failures, about 4,900 requests per second, and a 14.7ms p95 from the final swipe to the match reaching the host's phone.

    TypeScript / Node.js / Express / Socket.io / REST APIs
